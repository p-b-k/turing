Turning Machine and other, similar fun
=======================================
Also starting to add lambda calculus helper tool

This is basically just a project to write a turing machine and use it go to through some exersizes in a book

Building
------------------------------------------------
Standard rust build from root.  
`$ cargo build` puts the built files in target/debug.  

Running
------------------------------------------------
There are a few different executables in the debug folder:

1. **adder**
  * Probably best ignored. It was an early pass, it just adds 2 numbers, prints the states and the final result in base 1
  * `$ adder <number> <number>`

2. **symbolic**

3. **tcalc**
